## Defect avoided

The first extractor draft used raw `entt::to_integral` values, both for `ObjectId` and to sort change sets. The verifier's scene-identity rule rejected it, because recyclable EnTT handles must not leak into scene-facing identity. The extractor now takes an optional durable `ObjectId` source and processes changes in signal order, which keeps row assignment deterministic.
