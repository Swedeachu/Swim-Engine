# Item 45 validation — September 22, 2026

Item 45 adds the bindless texture/sampler table with timeline-safe element reuse. Contract: [GPU resource residency](../GpuResidency.md#bindless-textures-and-samplers-item-45). The work spans shader reflection (runtime-sized arrays), the RHI contract and Vulkan backend (explicit shared descriptor spaces, update-after-bind bindings), `Render::BindlessResourceTable`, `Render::GpuSamplerCache` and the `AssetResidencyService` registration step.

The engine runtime does not construct the table yet. The transitional renderer keeps its own descriptor path, and nothing legacy was retired.

## What the native smoke checks

Every step runs one compute dispatch through `BindlessResourceTable::GetTable()` in space 1 of a layout whose explicit space is visible to vertex, fragment and compute.

1. Two textures and two cached samplers (nearest and linear) are registered, and the four pairings are sampled at a texel edge along with the fallback pair. Nearest and linear filtering give different, exact results.
2. Frame A reads elements 1 and 2. Without waiting for it, element 3 is written. This exercises update-unused-while-pending.
3. Element 2 is released against A's timeline point. A registration made before `Collect` must receive element 4.
4. After the drain, `Collect` rewrites element 2 to the fallback. A dispatch through the stale index 2 must sample the fallback texture.
5. A new texture then reuses element 2 with a new generation, and the shader sees it.
6. Everything is released, and the collected counts and statistics are checked.
