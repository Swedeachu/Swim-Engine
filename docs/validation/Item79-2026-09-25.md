## Native smoke on a software device

The container has no GPU and no lavapipe package, so SwiftShader was built from source (Subzero backend) and run with SDL's offscreen video driver. SwiftShader does not expose `shaderDrawParameters`, which `SV_VertexID`/`SV_InstanceID` need in this Slang version, so that run used a local variant of `UiQuad.slang` with `SV_VulkanVertexID`/`SV_VulkanInstanceID` (identical otherwise; not committed) and validation disabled.

### Bugs found by the run

- **Flipped image.** The vertex stage wrote +Y-down NDC, but the RHI's clip space is +Y-up (the Vulkan backend flips the viewport). The CPU reference cannot see this, so the whole image was mirrored vertically (43 % outliers). The shader now negates NDC y; `SV_Position` in the fragment stage was already top-left-origin pixels.
- **scRGB tolerance.** Errors on float targets were measured against 1.0, while UI white in scRGB is paper white / 80 (3.0 here), so MSDF edge coverage differences were over-weighted (1.3 % outliers). Errors are now measured in units of UI white with the same 2.5-LSB tolerance for every encoding.
- **Invalid export.** The atlas-replacement frame exported a color target without `Sampled` usage to `ShaderRead`; the target now has `Sampled` usage.
