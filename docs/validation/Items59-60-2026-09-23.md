## Native smoke design

1. **BRDF probe:** 96 random inputs (random view, light, base color, metallic, and roughness in [0.05, 1]) go through `StandardPbrEvaluateBrdf` in a compute shader. Each result must equal `StandardPbr::EvaluateBrdf` within `1e-5 + 2e-3 · |value|`.
2. **Material draw:** six 6×6 quads in a 3×2 grid are drawn through `GpuVisibility` (single phase, `DrawVisibilityBin` on the adapter's path) into an `RGBA16Float` target with reverse-Z depth. Materials come from a 16-row `GpuMaterialTable`, and textures and samplers from a `BindlessResourceTable` in space 1. All textures are 4×4 single colors, so filtering cannot change a sample.

   | Object | Material |
   | --- | --- |
   | 0 | Dielectric with an sRGB base-color texture |
   | 1 | Metallic-roughness texture (G roughness, B metallic) × factors |
   | 2 | Tangent-space normal map (derivative tangent frame) over an sRGB base color |
   | 3 | Occlusion (strength 0.8) and sRGB emissive texture × factor |
   | 4 | Alpha 0.3 with `AlphaMask` (cutoff 0.5): discarded, so the clear color remains |
   | 5 | Material index 999: shaded with the fallback row (template defaults) |

   Each object's pixel must equal `StandardPbr::Shade` of the same material, with texels decoded as the GPU decodes them, within `4e-3 + 1.2%` (half-float storage and hardware sRGB decode). A pixel between the quads stays clear.
3. **Updates:**
   - Frame 2 edits object 0's material (factor and base-color texture), creates a replacement for object 1 and releases object 1's old material. Exactly 2 rows upload, and the pixels follow.
   - After `Collect`, frame 3 uploads exactly 1 row: the retired row, returned to the defaults.
