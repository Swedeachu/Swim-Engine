## Defects found

- **GPU-AV budget:** the first version loaded the previous transform rows and both view-projection matrices element by element, which took the opaque program from 72 to 78 instrumented accesses. Copying the six transform rows and the eight projection rows through one loop each brings it back to 72. `ShaderCompiler.GpuAvBudget` caught it without a GPU.
- **Slang name clash:** a local variable named `normalize` shadowed the intrinsic. It is now `inverseTotal`, in the CPU reference as well.
- **Test-only:** the first CPU ghosting test measured a trail pixel whose whole neighborhood was background. There, the min/max box alone removes the ghost, whatever the gamma. The test now measures the pixel next to the square, where only the dilated velocity prevents the ghost.
