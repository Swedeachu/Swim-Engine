### Native smoke design

The scene is a 20×20 grid of unit quads at z = 0 with a 24×24 wall quad at z = 5 in front of its middle. The view is a 40×40 reverse-Z orthographic window at 256×256. Every frame records:

1. early cull;
2. indirect draw, clearing color and depth to 0;
3. the HZB (8 mips);
4. late cull;
5. indirect draw, loading color and depth;
6. readbacks of both phases' statistics, counts and draw records, every HZB mip, and the image.

Checks per frame:

- **Statistics and draw sets:** early and late statistics and draw sets equal `RunVisibilityReference`. The late reference is fed `HzbReference::FromMips` of the GPU's own pyramid, so the comparison is exact.
- **Pyramid:** every mip above 0 equals the CPU reduction of the mip below. Mip 0 holds only clear, grid or wall depth.
- **Draws:** no row is drawn by both phases.
- **Pixels:** each in-view grid object's sample pixel shows the object, or the wall where the wall covers it. No pixel shows an object that was not drawn.

The five frames and their expected counts:

| Frame | Situation | Expected |
| --- | --- | --- |
| 1 | Fresh history | 0 early draws, 290 late draws, 0 occluded |
| 2 | Everything visible last frame | 290 early draws, 0 late draws |
| 3 | Steady state | 36 occluded, 254 early draws, 0 late draws |
| 4 | Wall teleported to x = 1000 | the 36 revealed objects are drawn late in the same frame |
| 5 | Wall back, with `CameraCut` | 290 early draws, 0 late draws |

The expected counts (289 grid spheres plus the wall in view, and the 6×6 occluded block) and the floor margins of the projected rectangles (at least 0.05 px) were computed with an independent Python model of the rasterized depth, the HZB and the test.

## Defects found

- **Use-after-free in the first `HzbBuilder` draft (found by AddressSanitizer).** It kept a reference to `graph.GetDesc(depth)` across `graph.CreateTexture`, which can reallocate the graph's resource list. The descriptor is now copied.
- **Previous pass: MSVC C4267 in `ShaderStructuredElementTests.cpp`.** `offsetof` narrowed to `uint32` inside `std::pair` initializers; the values are now cast explicitly.
