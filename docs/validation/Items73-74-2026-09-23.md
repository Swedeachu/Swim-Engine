### Design notes checked by the tests

- **Bit-reproducible bloom:** every downsample tap sits on a texel corner, so it is an exact 2×2 box of `Load`s, and the upsample tent is an exact 4×4 `Load` kernel. No hardware bilinear filtering is involved, so the CPU definition and the GPU differ only by float rounding and the binary16 store. `Post::RoundToHalf` mirrors the store.
- **Deterministic exposure:** the histogram uses integer atomics, and the average runs in one GPU thread in the same order as `Post::UpdateExposure`.
- **Exact grading identity:** default grading sets `GradingEnabled = 0`, so no `pow(x, 1)` rounding reaches the image.

## Defects found

- **Slang name clash:** the tone-mapper constants and functions shared names (`PostToneMapAces`, …). The constants are now `PostOperator*`.
- **Test-only:**
  - A `SWIM_CHECK_EQUAL` on a member of a temporary vector was dangling; it now uses a local.
  - The mock export of a storage-only output needed `CopySource`, not `ShaderRead`.
  - The GPU-AV budget's "counter is broken" check now applies to the total, because the upsample program legitimately has no buffer accesses.
- The mock command list now also records `BindComputePipeline`.
